# Лабораторная работа №6. Автоматизированное тестирование Python-программ

* **Тема:** Автоматизированное тестирование Python-приложений с использованием фреймворка `pytest`, проектирование модульных и интеграционных тестов, изоляция зависимостей и анализ покрытия кода.
* **Вариант:** 3 (Интернет-магазин).

---

## 1. Описание проекта

Проект представляет собой модуль предметной области интернет-магазина (`shop`), включающий:
* Управление товарами каталога (`Product`): валидация цен, количеств, названий.
* Сервисную логику (`CatalogService`): добавление, поиск по ID, регистронезависимая фильтрация по категориям, расчет суммарной стоимости запасов с учетом гибких политик скидок, выбор самого дорогого товара.
* Асинхронную интеграцию с внешним поставщиком складских остатков (`ExternalInventoryProvider`).
* Импорт данных из формата CSV с валидацией строк и экспорт каталога в JSON-отчеты.
* Конфигурацию параметров системы (порог минимального остатка) через переменные окружения (`MIN_STOCK_THRESHOLD`).
